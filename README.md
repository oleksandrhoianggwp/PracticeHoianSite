- **Кафедра:** комп'ютерних наук та інформаційних систем
- **Спеціальність:** 126 Інформаційні системи та технології
- **Термін практики:** 16.03.2026 – 24.04.2026

## Локально

Це звичайний статичний сайт — один HTML-файл + папка зі скріншотами.
Достатньо відкрити `index.html` у браузері подвійним кліком, або запустити локальний сервер:

```bash
python -m http.server 8000
# далі: http://localhost:8000
```

## Структура

- `index.html` — увесь сайт (HTML + CSS + JS у одному файлі)
- `screenshots/` — зображення інтерфейсу платформи ColdOutreach

## Як це задеплоєно

GitHub Pages з гілки `main`, корінь репозиторію.
**Settings → Pages → Source:** `Deploy from a branch` → **Branch:** `main` / `(root)`.
Кожний `git push` у `main` автоматично оновлює сайт через ~30 секунд.
