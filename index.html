Розділ 2 · Індивідуальне завдання

Продукт: ColdOutreach

B2B SaaS-платформа для автоматизації холодного outreach. Користувач знаходить релевантні компанії та контакти, запускає мультиканальні Sequences (Email + LinkedIn + Calls) та відстежує конверсію в єдиному інтерфейсі.

🎯

Мета

Скоротити час від ідеї холодної кампанії до першого ліда з тижнів до годин завдяки автоматизації пошуку, персоналізації та доставки повідомлень.

👨‍💼

Цільова аудиторія

Sales- та BDR-команди в B2B-сегменті, агенції з лідогенерації, продуктові стартапи, що шукають outbound-канал росту.

🚀

Застосування

Пошук компаній за 6+ фільтрами (Industry, Market Segment, Job Postings, Location), Drill-down до контактів, Sequences з A/B-кроками, AI-персоналізація на GPT-4o.

Розділ 2 · Реалізований функціонал

Що було реалізовано за період практики

Повний список модулів, які я особисто розробляв або в розробку яких суттєво долучався.

🔐 Auth & RBAC Backend
JWT-автентифікація, refresh-токени, ролі та permissions через FastAPI Depends. Реалізовано: /auth/register, /login, /refresh, /me + декоратори RBAC.
🏢 Companies & Contacts Full-stack
Search з 6+ фільтрами (Industry, Market Segment, Location, Job Postings, Company Search), drill-down: компанія → контакти → інші співробітники. SQLAlchemy моделі, repository-pattern, REST API, React-сторінки на MUI.
🔄 Sequences Full-stack
CRUD послідовностей, state-machine (start / pause / finish / clone), мульти-крокові кампанії з A/B-тестуванням, drill-down по контактам та компаніям, статистика по кожному кроку.
🔌 Integrations Backend
OAuth-флоу для Gmail / Outlook / Google Calendar / Outlook Calendar; LinkedIn cookie-auth; обмін кодом на токен, безпечне збереження, refresh-логіка, rate limiting та retry з експоненційним бекофом.
🤖 AI Search & Personalization AI
Multi-angle AI-пошук на GPT-4o з планувальником ракурсів (angle planner), стрімінговою обробкою, snippet-extractor для витягування ключових фактів, cost-tracker для обліку токенів. Інтеграції: OpenAI Web Search, Tavily, Exa.
📊 Analytics Full-stack
Dashboard з overview-метриками, sequence funnel (Scheduled → Delivered → Bounced → Reply → Interested → Opt-out), drill-down по контакту/компанії. Оптимізовано через selectinload/joinedload + Redis-кеш.
⚙️ Background Tasks Async
Celery + Redis: відправка Sequence-кроків за розкладом (Celery Beat), фоновий збір даних, парсинг funding-новин та вакансій, web-скрейпінг через BeautifulSoup.
📅 Calendar & Bookings Full-stack
Підключення Google/Outlook Calendar, відображення доступних слотів, автоматичне резервування часу при бронюванні зустрічі клієнтом, синхронізація з Sequence.
🧪 Tests & Quality Quality
pytest unit + integration тести на сервіси, репозиторії та API, валідатори на Pydantic + бізнес-правила в сервісному шарі, code review від команди.
